# assessment
This task is part of an assessment to create an image processing pipeline using Python and OpenCV (cv2). This assessment consists of two tasks. The first task is to perform a series of transformations on an input image, including grayscale conversion, Gaussian blurring, and Canny edge detection. The processed images are saved to an output directory and displayed for visualization. The second task is to create a color detector using a webcam. 
To run the program:
Install all the required dependencies using
** pip install -r requirements.txt**
Then run 
**python manipulation.py**
for the first task. 
**python colordetector.py** for the second task.
